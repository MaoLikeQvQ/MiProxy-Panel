# MiProxy Panel 使用说明

适用于 `v0.1.0`。程序同时提供 Web 面板与 SSH 终端界面。下载文件选择见同版本 `downloads.md`，在线文档位于 [MiProxy-Panel](https://github.com/MaoLikeQvQ/MiProxy-Panel)。

## 1. 安装与打开

### Linux / OpenWrt

Linux systemd 环境执行：

~~~sh
curl -fL https://github.com/MaoLikeQvQ/MiProxy-Panel/releases/latest/download/install.sh -o /tmp/miproxy-install.sh
sudo sh /tmp/miproxy-install.sh
sudo miproxy
~~~

OpenWrt root SSH 中执行时去掉 `sudo`。安装器会安装系统服务、开启开机启动并启动面板，保留已有环境文件与配置。需要离线安装时，下载同版本的二进制、`deploy.tar.gz` 与 `checksums.txt`，按 `downloads.md` 校验安装。

Web 默认位于设备的 `http://127.0.0.1:8787`。从自己电脑访问远程设备时先建立 SSH 转发：

~~~sh
ssh -L 8787:127.0.0.1:8787 用户名@设备地址
~~~

然后在电脑浏览器打开 `http://127.0.0.1:8787`。需要局域网直接访问时，在设备 `/etc/miproxy-panel.env` 设置 `PANEL_LISTEN=0.0.0.0:8787` 和 `PANEL_PASSWORD` 后重启服务，Web 登录用户名为 `admin`。终端通过本机 Unix Socket 连接，不使用 Web 密码。

### macOS

Apple 芯片下载 `miproxy-panel_darwin_arm64`，Intel Mac 下载 `miproxy-panel_darwin_amd64`，同时下载 `checksums.txt`。下面以 Apple 芯片为例，在下载目录执行：

~~~sh
awk '$2 == "miproxy-panel_darwin_arm64"' checksums.txt | shasum -a 256 -c -
chmod +x miproxy-panel_darwin_arm64
mkdir -p config
PANEL_CONFIG="$PWD/config/config.yaml" ./miproxy-panel_darwin_arm64 serve
~~~

保持该终端运行，在浏览器打开 `http://127.0.0.1:8787`。另开终端，切换到同一目录，执行：

~~~sh
PANEL_CONFIG="$PWD/config/config.yaml" ./miproxy-panel_darwin_arm64 tui
~~~

Intel Mac 将文件名中的 `arm64` 换为 `amd64`。两端需要使用相同 `PANEL_CONFIG`，才能通过同一 Socket 通信。macOS 版是命令行程序，没有 `.app` 安装器；系统服务安装、服务菜单及自动替换更新面向 Linux / OpenWrt。关闭后台终端或按 `Ctrl+C` 会停止面板及其托管的内核；外部应用内核仍由原应用管理。

## 2. 连接或安装内核

首次打开 Web 时，未连接内核会弹出「内核管理」并自动检测。后续从概览的「管理内核」进入。

- 检测到 Sparkle、ShellCrash、OpenClash 等正在运行且可接入的实例，点击「连接现有内核」。用户通常无需填写路径和端口；检测失败、无权限或控制接口未启用时，根据提示到原应用检查。
- 检测到未运行的可执行文件，可选「使用并启动」，使用面板自己的配置启动。
- 没有可用内核时，点击「安装并连接」。下载过程显示阶段、已下载字节、可用时的百分比与速度；等待状态变为「已连接」。
- 已连接外部内核时，对应来源保持选中。需要托管内核时选择「使用面板内核」，再安装或启动。

自动检测只检查运行面板的设备，不扫描整个局域网。浏览器运行在哪台电脑不影响检测范围。某些原应用未开放控制接口或配置受权限保护时，面板无法自动接入。

外部内核与面板托管内核的配置生效方式不同：

| 当前连接 | 查看状态、节点与日志 | 保存规则和订阅配置 |
| --- | --- | --- |
| 面板托管内核 | 读取真实运行状态 | 校验、保存并重载，成功后生效 |
| Sparkle / ShellCrash / OpenClash 等外部内核 | 读取其真实运行状态，支持允许的节点切换与运行操作 | Web 修改保留为草稿，导出后在原应用应用；终端不会替原应用应用订阅 |

## 3. 导入和应用订阅

1. Web 进入「订阅」→「导入订阅」，选择订阅链接或本地 YAML，填写名称并导入。支持包含节点或代理集合的单份 UTF-8 Clash / Mihomo YAML，大小不超过 2 MiB。
2. 导入后点目标订阅的「应用订阅」。面板合并节点、代理组和分流规则，保留本地控制接口、端口与 DNS 等设置，并叠加已保存的覆写。
3. 应用时页面显示全局加载，等待校验、保存、重载完成。仅保存成功但重载失败时会明确提示，不能视为已生效。
4. 订阅自带规则自动收进「订阅规则」组，保持原有顺序和各条策略；纯节点订阅保留当前规则。
5. 远程订阅的「更新」只重新下载内容，之后仍需点击「应用订阅」。移除订阅只删除记录，当前运行配置不立即改变。

从终端操作时按 `3` 进入订阅页，`a` 导入链接，`f` 导入设备上的 YAML 文件，`Enter` / `s` 应用，`u` 更新，`d` 删除。选中标记只表示光标位置，`[使用中]` 才表示已成功应用的订阅。

## 4. 节点选择与测速

Web 在「代理组」的运行视图中选择代理组、查看节点并测速，手动选择组可切换节点；自动选择组由内核决定。终端按 `4`，进入组后 `Enter` 切换节点，`t` 测速，`g` 返回组列表。测速结果不等同于真实业务访问成功。

## 5. 添加普通规则

Web「规则」使用一个列表展示规则顺序、匹配条件及当前策略，不再区分运行规则、配置规则或规则集标签。

1. 点击刷新旁的「添加规则」，直接打开弹窗。
2. 选择完整域名、域名及其子域名、关键词、IP 地址或网段等匹配方式，填写匹配条件。
3. 在「匹配后走」选择直连、拦截或代理组 / 节点，也可以手动填写策略名称。
4. 面板托管模式下点击「保存并生效」；新规则默认位于订阅规则组或兜底规则前。配置可编辑时，列表内支持编辑、删除、撤销删除、拖动与方向键排序。

点击订阅规则组行内的规则数量，可以展开查看全部内容。自动归组只是组织配置，未删减实际匹配规则。临时启停开关只改变内核运行状态，重启或重载后可能恢复；需要长期修改时编辑配置。

重载失败或存在未保存草稿时，列表显示配置内容并明确提示，不能把它当作已生效规则。外部内核的草稿修改需导出后在原应用应用。

## 6. 订阅远程规则集

例如需要订阅一个广告拦截规则文件：

1. 「添加规则」→ 匹配方式选择「规则集」。
2. 「规则来源」选择「订阅地址」。填写规则集名称和完整 HTTP / HTTPS 地址。
3. 按文件实际内容选择规则类型：`classical` 为经典匹配规则，`domain` 为域名列表，`ipcidr` 为 IP 段列表。
4. 选择 `yaml` / `text` / `mrs` 格式。MRS 仅支持域名或 IP 段，不能搭配 classical。
5. 设置更新间隔，单位秒；默认 `86400` 为每天，`0` 为仅手动更新。
6. 「匹配后走」选择「拦截（REJECT）」；需要代理或直连时改选相应策略，然后保存。

保存会同时写入 `rule-providers` 来源和前置的 `RULE-SET,名称,策略` 引用。已有来源无需重复新增，切换「规则来源」为「已有规则集」，填写已配置的名称即可引用。重名、无效地址和不兼容格式会阻止保存。

内核按 URL 获取远程规则文件。面板支持规则集地址配置，不等于已验证该地址在所有设备均可下载；具体错误以校验、重载和内核日志为准。普通代理订阅链接与规则集文件地址是两类输入，不能互换。

## 7. 覆写、YAML 与日志

「覆写」用于保存自定义设置；普通映射递归合并，列表整体替换。想长期前置规则时使用 `prepend-rules`，例如：

~~~yaml
prepend-rules:
  - DOMAIN-SUFFIX,example.com,DIRECT
~~~

YAML 编辑器可查看完整草稿，`Ctrl` / `⌘` + `F` 搜索，`Ctrl` / `⌘` + `S` 保存。配置应用准确区分校验、保存与重载；失败时先看提示详情。

「日志」仅在内核已连接且页面处于接收状态时读取。未连接时先检查内核管理；下载失败先检查 GitHub、订阅源的网络和有效期。面板不会自动设置系统代理、透明代理或路由规则；节点已连接但浏览器无法访问时，还需要确认实际流量走到代理端口。

## 8. 服务、更新与卸载

终端 `miproxy` 中按 `2` 管理服务启停、重启与开机启动；操作前核对确认说明。停止面板会停止它托管的内核，退出终端菜单不会停止后台。

按 `7` 检查 GitHub 正式版本，确认后下载、校验并替换面板；完成后退出并重新打开终端。面板内核更新为独立操作，外部内核通过原应用更新。卸载会移除服务和命令，保留配置、环境文件与内核文件。

常用终端按键：`↑` / `↓` 选择，`Enter` 进入，`Tab` 切换焦点，`Esc` 返回，`q` / `0` 退出，`Ctrl+L` 重绘。窗口至少 40 列 × 16 行，字号由终端软件设置。

## 9. 最小自测流程

使用独立测试配置目录和可丢弃的测试订阅：

1. 启动面板，检测或安装内核，确认「已连接」。
2. 导入测试订阅并应用，确认全局加载结束且应用成功。
3. 检查代理组、测速及手动切换节点，使用实际代理端口完成一次访问。
4. 添加一个测试域名规则，再添加一个测试规则集地址，确认策略与顺序正确；删除并撤销一次。
5. 重新打开规则页和日志页，确认内容与内核一致；测试一次错误地址或断开内核时的提示。
6. 仅在可丢弃设备上验证服务启停、重启、更新与卸载。OpenWrt 真机和代理接管需要单独验收。
