# MiProxy Panel v0.1.0

首个正式版本，通过 Web 和 SSH 终端管理 Mihomo。二进制内嵌 Web 页面，无需在目标设备安装 Go 或 Node.js；Mihomo 内核单独检测或下载。

## 主要功能与本次变更

- 提供运行概览、实时指标、流量及连接历史、代理组切换、节点测速和实时日志，适配桌面、手机与明暗主题。
- 内核未连接时自动打开管理对话框，检测已有本地进程、安装路径和控制接口；支持接入 Sparkle / ShellCrash / OpenClash 等已有实例，连接后显示实际选中的来源。
- 支持面板托管 Mihomo 的安装、启动和更新；显示下载阶段、字节数、可用时的百分比和速度，复用网络代理设置。外部实例继续由原应用管理。
- 支持链接和本地 YAML 订阅导入、更新、切换与删除；应用时全局加载，并区分校验、保存与重载结果，重载失败不标记为应用成功。
- 应用完整订阅时自动将分流规则收进保留原顺序与各条策略的「订阅规则」组，按需准备 Geo 数据，并支持叠加覆写。
- 规则页统一为一个列表，移除运行规则 / 配置规则 / 规则集标签；刷新旁添加按钮直接打开弹窗。支持可编辑配置的编辑、删除撤销与排序，规则组在列表内展开。
- 添加规则集时可填写 HTTP / HTTPS 订阅地址、规则类型、文件格式、更新间隔及策略，也可引用已有规则集；配置来源和分流引用一并保存。
- 内核未连接时停止日志请求；未成功重载及外部内核草稿明确提示，避免误判为已生效。
- 新增 `miproxy` 终端菜单，覆盖服务启停与开机启动、订阅、节点、内核、诊断、GitHub 更新和卸载。
- 提供 Linux systemd / OpenWrt procd 安装器、离线部署包、SHA-256 校验和 13 个 Linux / macOS 架构目标，正式包由 GitHub Actions 构建。

## 下载怎么选

| 环境 | 文件 |
| --- | --- |
| Intel / AMD 64 位 Linux、x86 软路由 / NAS | `miproxy-panel_linux_amd64` |
| ARM64 Linux / OpenWrt、64 位系统树莓派 | `miproxy-panel_linux_arm64` |
| 其他路由器或嵌入式设备 | 按系统位数、ARM 版本、MIPS 字节序选择，详见 `downloads.md` |
| Apple 芯片 Mac | `miproxy-panel_darwin_arm64` |
| Intel Mac | `miproxy-panel_darwin_amd64` |

Linux / OpenWrt 推荐执行 README 中的在线安装命令，由安装器自动选包。离线安装需要同版本的目标二进制、`deploy.tar.gz` 和 `checksums.txt`。`usage.md` 是完整使用说明，`downloads.md` 逐个解释所有产物和适用环境。GitHub 的 Source code 文件为源码包。

## 使用与验证边界

- 面板不自动设置系统代理、透明代理或接管路由流量；这些设置由实际部署环境负责。
- 外部内核的配置继续由原应用保存和应用；面板中的修改作为草稿导出。
- 发布工作流执行前后端检查、四套模拟 API 浏览器回归、全架构交叉编译及原生 Ubuntu systemd 安装验收。
- OpenWrt 路由器真机、旧 ARM / MIPS 等设备兼容性和各设备的实际流量接管仍需现场验收；交叉编译和模拟接口测试不代表这些验证已完成。
- 当前不提供 Windows、macOS `.app` / `.dmg`、Linux `.deb` / `.rpm`、OpenWrt `.ipk` / `.apk` 或预构建容器镜像。
